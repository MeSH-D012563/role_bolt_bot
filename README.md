# Telegram Mini‑Games Bot

Асинхронный Telegram‑бот с тремя мини‑играми на внутреннюю валюту и рейтингами.

## Возможности
- 🎰 Слот‑автомат с множителями.
- 🎲 Дуэль на костях с подтверждением участия кнопкой.
- 🏀 Баскетбол с банком и возможностью забрать выигрыш или продолжить.
- Топ по балансу и по проигрышам.
- Профиль доступен только в личных сообщениях.

## Быстрый старт
1. Установите зависимости:
```bash
pip install -r requirements.txt
```
2. Создайте `.env` по примеру `.env.example` и укажите `BOT_TOKEN`.
3. Запустите бота:
```bash
python -m bot
```

## Команды
- `/start` — создать профиль.
- `/help` — справка по командам (только ЛС).
- `/help_shop` — подробности магазина (только ЛС).
- `/shop_help` — алиас справки по магазину.
- `/shop` — список товаров (только ЛС).
- `/buy <item_id> [@юзер]` — покупка товара.
- `/set_title <title_id|none>` — выбор титула.
- `/slot <ставка>` — слот‑машина.
- `/dice <ставка> <@юзер>` или reply — дуэль.
- `/basket <ставка>` — начать баскетбол.
- `/basket_continue` — продолжить баскетбол.
- `/basket_cashout` — забрать банк.
- `/profile` — профиль (только ЛС).
- `/top_balance` — топ по балансу.
- `/top_lost` — топ по проигрышам.

## Правила игр
### 🎰 Слот
- Ставка списывается сразу.
- Выплата зависит от значения анимации (🎰 `dice.value` 1..64):
  - `>= 64` → x5
  - `>= 60` → x3
  - `>= 48` → x2
  - `>= 32` → x1.2
  - ниже → проигрыш

### 🎲 Дуэль
- Инициатор указывает ставку и соперника.
- Соперник подтверждает участие кнопкой.
- Бросаются две кости. Победитель забирает банк.
- Ничья — ставки возвращаются.
- Если дуэль не принята за 120 секунд, ставка инициатора возвращается.

### 🏀 Баскетбол
- Ставка списывается, банк стартует со ставки.
- Попадание (значения 4–5) увеличивает банк в 1.5 раза.
- Игрок может продолжить или забрать банк.
- Промах — банк сгорает.

## Настройки
Все ключевые параметры вынесены в `bot/config.py`:
- стартовый баланс
- валюта
- множители
- тайм‑аут дуэли
- задержка анимации
- параметры магазина

## Магазин
- Покупки совершаются за внутреннюю валюту.
- Наказания применяются к указанной цели в группе.
- Защита блокирует бан/мут на время действия.
- Титулы уникальны и доступны одному игроку.
- Для банов/мутов бот должен быть администратором чата.
- В /shop доступны кнопки фильтрации и быстрой покупки.
