# Telegram Mini‑Games Bot

Асинхронный Telegram‑бот на `aiogram 3` с внутренней валютой, мини‑играми, магазином и уникальными титулами.

## Возможности
- 🎰 `slot` — слот на `sendDice` с выплатами по комбинациям символов.
- 🎲 `dice` — дуэль между двумя игроками без комиссии бота.
- 🏀 `basket` — риск‑игра с растущим банком и ручным кэшаутом.
- 🛍 Магазин с наказаниями, защитами и уникальными титулами.
- 👤 Профиль, переводы, ежедневный бонус и рейтинги.

## Быстрый старт
1. Установите зависимости:
```bash
pip install -r requirements.txt
```
2. Создайте `.env` по примеру `.env.example` и заполните `BOT_TOKEN`.
3. Запустите бота:
```bash
python -m bot
```

## Команды
- `/start` — создать профиль.
- `/help` — справка по командам в ЛС.
- `/profile` — профиль в ЛС.
- `/get_cash` — ежедневный бонус.
- `/pay <сумма>` — перевод ответом на сообщение.
- `/slot <ставка>` — слот.
- `/dice <ставка>` — дуэль ответом на сообщение в группе.
- `/basket <ставка>` — начать баскетбол.
- `/basket_continue` — продолжить баскетбол.
- `/basket_cashout` — забрать банк.
- `/shop` — магазин в ЛС.
- `/help_shop` или `/shop_help` — справка по магазину.
- `/buy <item_id>` — покупка товара.
- `/set_title <title_id|none>` — выбрать активный титул.
- `/sell_title <цена>` — выставить активный титул на продажу.
- `/sell_title_now` — мгновенно продать активный титул боту за `90%` цены с подтверждением в ЛС.
- `/gift_title` — подарить активный титул ответом на сообщение.
- `/top_balance` — топ по балансу.
- `/top_lost` — топ по проигрышам.

## Экономика
- Стартовый баланс: `200` `bolt_coin`.
- Ежедневный бонус: `75` `bolt_coin` каждые `12` часов.
- Лимит ставки: от `1` до `1_000_000`.
- Задержка анимации: `2.0` секунды.
- Налог на титулы: `2.5%` в сутки от суммарной стоимости титулов, если у игрока `2+` титула.

## Правила игр
### 🎰 Слот
- Telegram возвращает `dice.value` от `1` до `64`.
- Бот декодирует значение в 3 символа: `BAR`, `🍒`, `🍋`, `7️⃣`.
- Выплаты:
  - `7️⃣ 7️⃣ 7️⃣` → `x6.2`
  - `BAR BAR BAR` → `x3.8`
  - `🍒 🍒 🍒` → `x2.6`
  - `🍋 🍋 🍋` → `x1.6`
  - пара `7️⃣` → `x1.55`
  - пара `BAR` → `x1.35`
  - пара `🍒` → `x1.15`
  - пара `🍋` → `x1.0`
  - остальное → проигрыш
- Некоторые титулы усиливают слот или возвращают часть ставки при проигрыше.

### 🎲 Дуэль
- Работает только в группах.
- Инициатор вносит ставку и ждёт подтверждения соперника.
- Если дуэль не принята за `120` секунд, ставка возвращается.
- Победитель получает банк, ничья возвращает ставки.
- Титулы не усиливают дуэли, чтобы PvP оставался честным.

### 🏀 Баскетбол
- Попадание — значения `4` или `5`.
- Каждое попадание умножает текущий банк на `x2.35`.
- После попадания можно продолжить или забрать банк.
- Промах сжигает банк.
- Некоторые титулы усиливают рост банка или возвращают часть исходной ставки после промаха.

## Титулы
- Каждый титул уникален и принадлежит только одному игроку.
- Титулы больше не дают один и тот же линейный бонус.
- Теперь у титулов разные роли, но они также выстроены по цене: чем дороже титул, тем сильнее его суммарный пакет баффов.
  - бонус к выплатам в `slot`
  - бонус к банку в `basket`
  - частичный возврат ставки при проигрыше
  - прибавка к `/get_cash`
  - скидка на защиты в магазине
- Примеры:
  - `title_wanderer` — усиливает ежедневный доход
  - `title_shadow` — страхует проигрыши
  - `title_marauder` — удешевляет защиты
  - `title_sovereign` — универсален для обеих PvE‑игр
- Первый титул не облагается налогом.
- Если у игрока `2+` титула, бот раз в `24` часа пытается списать налог.
- Если денег не хватает, начинается долг на `24` часа, а эффекты титулов отключаются.
- Если долг не погашен вовремя, бот конфискует один неактивный титул.
- Активный титул можно мгновенно продать боту за `90%` его цены в магазине.

## Магазин
- Наказания работают только в группах.
- Для банов и мутов бот должен быть администратором с правом ограничивать участников.
- Защита блокирует бан/мут на время действия.
- Если у активного титула есть скидка на защиты, она показывается прямо в `/shop`.
- Титулы с активным долгом нельзя покупать через магазин и рынок.

## Конфигурация
Главные параметры лежат в `bot/config.py`:
- экономика и лимиты
- коэффициенты игр
- таймеры дуэли и ежедневки
- товары магазина
- эффекты титулов
